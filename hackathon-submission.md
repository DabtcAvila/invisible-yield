## Project Description
Invisible Yield is the first truly automated yield farming protocol on StarkNet that makes DeFi accessible to everyone. Using AI-powered algorithms and ChipiPay's seamless wallet integration, we automatically optimize yields across 100+ strategies while users enjoy zero gas fees on StarkNet L2.

## Problem Statement
DeFi users face significant challenges:
- Lose $2.3B annually to gas fees
- Spend 15+ hours monthly managing yields
- 87% miss optimal opportunities due to complexity
- High barrier to entry for mainstream users

## Solution
Our platform offers:
- **AI-Powered Optimization:** Automatically rebalances across 100+ yield strategies
- **Zero Gas Fees:** Built on StarkNet L2 for maximum efficiency
- **ChipiPay Integration:** One-click connection, no seed phrases
- **Mobile-First:** Full app experience on any device
- **Non-Custodial:** Users maintain full control of their assets

## Technical Implementation

### Smart Contracts (Cairo)
- `yield_vault.cairo`: Core vault logic with deposit/withdraw/compound
- `yield_optimizer.cairo`: AI strategy selection and rebalancing
- `chipipay_adapter.cairo`: ChipiPay wallet integration

### Backend
- GraphQL API with Apollo Server
- Real-time yield tracking
- Strategy performance analytics

### Frontend
- HTML5 + TailwindCSS (Web)
- React Native (Mobile - in development)
- Chart.js for portfolio visualization
