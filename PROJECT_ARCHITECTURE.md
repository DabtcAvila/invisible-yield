## 🏗️ ARQUITECTURA TÉCNICA

### Frontend (Mobile-First)
- **Framework**: Next.js 14 + React Native
- **UI Library**: Tailwind CSS + Framer Motion
- **State**: Zustand + React Query
- **Auth**: Email magic links (no seed phrases)

### Backend Blockchain
- **L2**: Starknet (Account Abstraction nativo)
- **Smart Contracts**: Cairo 2.0
- **Wallet Infrastructure**: ChipiPay SDK
- **Bitcoin Integration**: Atomiq SDK (Lightning)

### Yield Generation
- **Primary**: Troves yield aggregator
- **Secondary**: Vesu lending protocols
- **Risk**: Automated rebalancing cada 6 horas

### Database & APIs
- **Primary DB**: Supabase (PostgreSQL)
- **Cache**: Redis
- **API**: GraphQL con Apollo Server
- **Real-time**: WebSockets
